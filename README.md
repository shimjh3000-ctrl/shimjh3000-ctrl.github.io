# MTSM Lab Website

Official website of the **Muscle Therapeutics & Stereochemical Medicine Laboratory**, led by Jae Ho Shim at Korea University College of Medicine.

## Live site

https://shimjh3000-ctrl.github.io/

## Research focus

- Skeletal-muscle wasting and homeostasis
- Exercise mimetics and myokine biology
- Stereochemistry-enabled medicinal chemistry
- Brain–muscle disease mechanisms
- Nanomedicine and targeted delivery
- Non-opioid pain therapeutics

## Technology

Static HTML, CSS, and vanilla JavaScript hosted with GitHub Pages. The site is responsive, accessible, bilingual on the main page, and has no external runtime dependencies.

## Updating

- Main content: `index.html`
- Publication list: `publications.html`
- Styling: `assets/styles.css`
- Interactions and language toggle: `assets/app.js`

Only publicly disclosed research should be added to this public repository. Unpublished manuscripts, confidential numerical results, and third-party copyrighted full texts must remain in access-controlled storage.
